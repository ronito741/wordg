# ⚡ Beginner-Friendly Wordlist Studio

> A sleek, modern, cyber-themed GUI application built with Python and Tkinter to help you easily generate customized wordlists for penetration testing, security labs, and CTFs.

---

## 🚀 Features

* **📁 Flexible Starting Sources:** Load words from an existing text file, type them manually on the fly, or let the computer generate random letter combinations.
* **🔢 Powerful Number Options:** Easily append single digits, double digits, common years, or custom number ranges (e.g., `0` to `9999`).
* **🔣 Special Symbols & Characters:** Integrate standard symbols (`!`, `@`, `#`, `$`, etc.) or add your own custom character sets.
* **⚙️ Advanced Formatting & Styles:** 
  * Keep Lowercase, Capitalize, Uppercase, or Reverse words.
  * Apply **Leet Speak (1337)** transformation automatically.
  * Choose precise placement (Prefix, Suffix, Middle, or Wrapped).
* **🎨 Clean Modern Interface:** Features a responsive cyberpunk dark theme with a live progress bar, real-time status updates, and a built-in log console.
* **🔒 Persistent Inputs:** Your inputs and selections stay populated after a generation finishes so you can tweak and re-run instantly!

### Prerequisites
Make sure you have **Python 3.x** installed on your system. Tkinter (used for the graphical interface) comes pre-installed with standard Python installations on Windows, macOS, and most Linux distributions.
